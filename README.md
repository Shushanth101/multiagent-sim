# multiagent-sim
A cool little sim where multiple agents interact, coordinate, and navigate dynamic spaces. Built to explore swarm behaviors, decision-making, and optimized flows.

## 🚀 Features

- ⚡ Multi-agent environment simulation
- 🧭 Agent-to-agent communication & coordination
- 🧠 Decision-making logic for individual agents
